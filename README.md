## 人生計劃（私人專案推進板）

網址：https://yangyang-shengming.github.io/plan/

`plan/index.html` 是羊羊自己用的人生計劃與專案推進板：今天要做的事、每個專案的下一步與推進紀錄、人生領域與目標、週回顧。

程式是公開的，但資料只存在使用者自己的瀏覽器（或使用者自己設定的秘密 Gist），不會存進這個資料夾。頁面設定了 noindex，作品集首頁也沒有連過去。
